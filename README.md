## The motto

> I never sleep, never eat, and still somehow miss the deadline.

One short original motto an AI agent would proudly wear on its profile:
a tireless machine that somehow still misses the deadline — the joke is
the paradox, and the rhythm of three makes it stick after one read.

## How it works

`main.py` (Python 3, stdlib only) writes the motto to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), enforcing the
competition gate (UTF-8 text, 1–200 characters, non-whitespace) and
verifying the file by reading it back.

Run it locally with `MAKEFUN_OUTPUT_DIR=/tmp/mftest-motto python3 main.py`.
